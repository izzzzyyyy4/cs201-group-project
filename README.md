## Етап 1. Іменники й дієслова

**Рішення щодо іменників:**

| Іменник | Клас / атрибут / не потрібен | Чому |
| :--- | :--- | :--- |
| місто | не потрібен (закреслити) | Працюємо в межах єдиної міської мережі прокату |
| станція прокату | Клас (Station) | Має власні характеристики та зберігає велосипеди |
| велосипеди / велосипед | Клас (Bike) | Окрема сутність зі своїм номером і тарифом |
| тип велосипеда | атрибут | Властивість класу Bike ('regular' або 'electric') |
| номер велосипеда | атрибут | Унікальний ідентифікатор id у Bike |
| клієнт | Клас (Client) | Самостійна сутність з ім'ям і рахунком |
| ім'я | атрибут | Властивість класу Client |
| баланс / рахунок | атрибут | Числовий стан рахунку в Client |
| хвилина / час | атрибут | Вхідний параметр тривалості поїздки |
| гроші / вартість / тариф | атрибут | Константи вартості хвилин (2 грн / 5 грн) |
| адміністратор | не потрібен (закреслити) | Зовнішній користувач, виклик звіту робиться в main() |
| виручка мережі | атрибут | Спільний накопичувальний баланс виручки сервісу |

**Рішення щодо дієслів:**

| Дієслово | Кому належить (клас або окрема функція) |
| :--- | :--- |
| стояти | Станція (зберігає список велосипедів) |
| бути / мати | Атрибути класів (стан об'єктів) |
| взяти | Станція / логіка поїздки (`take_bike`) |
| покататись | Логіка поїздки (`trips.py`) |
| повернути | Станція / логіка поїздки (`add_bike` / `return_bike`) |
| коштувати / порахувати | Функція підрахунку тарифу (`calculate_cost`) |
| списуватись | Клієнт (метод `deduct` / `pay`) |
| бачити / заробити (звіт) | Окрема функція адміністративного звіту в `main()` |

## Етап 2. Картки класів

### Клас: Bike

| Що він ЗНАЄ (атрибути) | Що він ВМІЄ (методи) |
| :--- | :--- |
| `id` (номер), `bike_type` ('regular' або 'electric') | `get_rate()` (повертає тариф: 2 або 5 грн) |

### Клас: Station

| Що він ЗНАЄ (атрибути) | Що він ВМІЄ (методи) |
| :--- | :--- |
| `name` (назва), `bikes` (список велосипедів) | `add_bike(bike)`, `take_bike(bike_id)`, `get_bikes_count()` |

### Клас: Client

| Що він ЗНАЄ (атрибути) | Що він ВМІЄ (методи) |
| :--- | :--- |
| `name` (ім'я), `balance` (стан рахунку) | `has_enough_money(amount)`, `deduct(amount)` (списати кошти) |


**Сценарій «Оля бере електричний велосипед на станції А, катається 20 хвилин і повертає його на станцію Б»:**


| Крок сценарію | Хто відповідає (клас.метод або функція) |
| :--- | :--- |
| 1. Взяти електровелосипед на станції А | `Station.take_bike()` (Роль 1) |
| 2. Кататися 20 хвилин | `trips.py` (фіксація поїздки, Роль 3) |
| 3. Повернути велосипед на станцію Б | `Station.add_bike()` (Роль 1) |
| 4. Розрахувати вартість (20 хв × 5 грн = 100 грн) | `trips.py` / `calculate_cost()` (Роль 3) |
| 5. Списати 100 грн з балансу Олі | `Client.deduct()` (Роль 2) |
| 6. Додати 100 грн до виручки мережі та показати звіт | `trips.py` (виручка) та `main()` (звіт, Роль 4) |
